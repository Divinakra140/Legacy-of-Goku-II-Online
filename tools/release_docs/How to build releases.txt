First off... do these in order champ.

If you changed the map, run the bake first (python3 -I ../tools/bake_earth.py from the project folder). You do this by copy pasting this command into terminal: 

cd "/Volumes/Gen2/Godot/Legacy of Goku/LoG2_Android_Build/project" && python3 -I ../tools/bake_earth.py

Then raise BUNDLE_VERSION in project/scripts/assets.gd, so phones load the new map.

For example it may say 45-4 so change it to 45-5

The bundle version only controls the game data packed inside the release: the map, content, mods and similar files. Devices copy that data out once and keep the copy. Raising the version tells them to copy it out again.

So you only raise it when you’ve changed data: a map bake, content edits, mods. Raising it when nothing changed doesn’t hurt anything. Devices would just unpack the same data again, which takes a few extra seconds on the first start.

Then to rebuild the three releases: double-click tools/build_release.command, or run it in Terminal. It packs the game data, builds all three releases, adds the guides, and zips.
